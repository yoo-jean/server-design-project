# 콘서트 좌석 예약 서비스 - 서버 설계 문서

본 문서는 **필수 과제(서버 설계 분석)**를 위해 작성된 저장소입니다.\
선정한 시나리오를 기반으로 **API 명세서 · ERD · 인프라 구성도**를
설계하였으며,\
프로젝트 구성원이 보더라도 바로 이해할 수 있도록 구조화하였습니다.

------------------------------------------------------------------------

## 1. 시나리오 선정

### **콘서트 좌석 예약 서비스**

사용자는 콘서트 회차를 선택하고, 개별 좌석을 예약할 수 있습니다.

-   대기열 토큰을 통한 트래픽 제어
-   임시 좌석 예약(TEMP_RESERVED) 후 결제 시 확정(CONFIRMED)
-   일정 시간 지나면 자동 만료(EXPIRED)
-   포인트 충전 및 결제 기능 포함

실제 대규모 트래픽을 고려한 구조를 기반으로 설계하였습니다.
